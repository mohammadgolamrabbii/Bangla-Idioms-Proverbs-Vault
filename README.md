## 🌟 এই প্রজেক্টের প্রধান বৈশিষ্ট্যসমূহ (Key Features)

- 💎 **১৪০+ প্রামাণ্য বাংলা বাগধারা (Idioms):** সঠিক অর্থ, ব্যাকরণিক প্রয়োগবাক্য, ভাবার্থভিত্তিক ইংরেজি সমার্থক (`English Equivalent`), ক্যাটাগরি এবং সার্চ ট্যাগসহ।
- 📜 **৩৫+ ঐতিহ্যবাহী প্রবাদ-প্রবচন (Proverbs):** ভাবার্থ, ইংরেজি সমার্থক প্রবচন (`Matching English Proverb`) এবং বাস্তব জীবনে প্রয়োগের প্রেক্ষাপট।
- ⚖️ **২০ জোড়া সমোচ্চারিত ভিন্নার্থক শব্দ (Homophones):** কুল/কূল, দিন/দীন, শব/সব, স্বাক্ষর/সাক্ষর ইত্যাদির বানানভেদে সুনির্দিষ্ট অর্থ, উদাহরণ ও বিসিএস পরীক্ষার গুরুত্ব নির্দেশিকা।
- ✂️ **৪৫+ বাক্য সংকোচন / এক কথায় প্রকাশ (One-Word Substitutions):** বিসিএস ও ভর্তি পরীক্ষায় সর্বাধিক কমনযোগ্য বাক্য সংক্ষেপণ।
- 🎯 **ইন্টারেক্টিভ কুইজ ইঞ্জিন (BCS & Admission Quiz):** তাৎক্ষণিক স্কোর, সঠিক উত্তরের ব্যাখ্যা ও রিয়েল-টাইম প্রগ্রেস ট্র্যাকিং।
- 🔍 **রিয়েল-টাইম সার্চ ও ফিল্টারিং:** যেকোনো শব্দ, অর্থ, বা ইংরেজি সমার্থক দিয়ে ক্ষণিক সময়ে ইনস্ট্যান্ট ফিল্টার।
- 📋 **এক-ক্লিকে কপি (One-Click Copy):** যেকোনো এন্ট্রি সহজেই কপি করে ডকুমেন্ট বা চ্যাটে ব্যবহারের সুবিধা।
- 🌓 **ডার্ক ও লাইট মোড:** দৃষ্টিনন্দন আধুনিক ইউজার ইন্টারফেস (Modern Glassmorphism UI)।
- 📦 **মাল্টিপল ফরম্যাট সাপোর্ট:** ওয়েব অ্যাপ ছাড়াও সরাসরি `JSON`, `CSV`, `Node.js CLI` এবং `Python SDK`-এর মাধ্যমে ডেটা ব্যবহারের সুযোগ।

## 💻 ডেভেলপার ও গবেষকদের জন্য ব্যবহারবিধি (Developer SDK & Usage)

### ১. কমান্ড লাইন টুল (CLI - Terminal Search & Quiz)

কোনো ইনস্টলেশন ছাড়াই সরাসরি রান করতে পারবেন:

```bash
# যেকোনো বাংলা বাগধারা বা শব্দ খুঁজুন
npx bangla-vault search "ডুমুর"

# ইংরেজি প্রতিশব্দ দিয়ে খুঁজুন
npx bangla-vault search "cunning"

# দৈবচয়ন (Random) বাগধারা ও প্রবাদ দেখুন
npx bangla-vault random

# ডেটাসেটের পরিসংখ্যান দেখুন
npx bangla-vault stats
```

### ২. সরাসরি জাভাস্ক্রিপ্ট / ওয়েব এপিআই ফেচ (REST API via GitHub Pages)

আপনার নিজস্ব ওয়েবসাইট বা অ্যাপে সরাসরি লাইভ ডেটা যুক্ত করুন:

```javascript
// ফেচ করুন সকল বাগধারা
fetch("https://mohammadgolamrabbii.github.io/Bangla-Idioms-Proverbs-Vault/data/idioms.json")
  .then(res => res.json())
  .then(idioms => {
    console.log(`মোট বাগধারা: ${idioms.length}`);
    console.log(idioms[0]);
  });
```

### ৩. পাইথন ইন্টিগ্রেশন (Python / Pandas / NLP / Machine Learning)

```python
import pandas as pd
import requests

# সরাসরি CSV লোড করুন Pandas DataFrame এ
csv_url = "https://raw.githubusercontent.com/mohammadgolamrabbii/Bangla-Idioms-Proverbs-Vault/main/data/csv/idioms.csv"
df = pd.read_csv(csv_url)

print("মোট রেকর্ড:", len(df))
print(df[["phrase", "meaning", "english_equivalent"]].head())
```

অথবা অন্তর্ভুক্ত পাইথন ক্লাস ব্যবহার করে:

```python
from sdk.python.bangla_vault import BanglaVault

vault = BanglaVault()
results = vault.search("চালাক")
print(results)
```
